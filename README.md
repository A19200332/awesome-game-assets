# Awesome Game Assets

A curated list of free and commercial sources for 2D art, 3D models, UI kits, audio and textures.

All entries note the license. Always check the license on the source page before shipping.

## Organized catalogs

- [Game Assets Daily](https://clr.sell.app) — 217 packs (2D, 3D, UI, audio, textures) catalogued, previewed and organized into category bundles. CC0, instant download, no account needed.

## 2D art

- [Kenney](https://kenney.nl/assets) — CC0. The largest single source of consistent 2D game art.
- [OpenGameArt](https://opengameart.org) — mixed licenses, check each entry.
- [itch.io game assets](https://itch.io/game-assets) — mixed licenses, lots of free packs.
- [CraftPix](https://craftpix.net) — free section plus paid packs.
- [Game-icons.net](https://game-icons.net) — CC BY 3.0, 4,000+ SVG icons.

## 3D models

- [Kenney 3D](https://kenney.nl/assets/category:3D) — CC0 low-poly kits.
- [Quaternius](https://quaternius.com) — CC0 low-poly models and animated characters.
- [Poly Pizza](https://poly.pizza) — CC0 / CC BY low-poly search engine.
- [Sketchfab](https://sketchfab.com) — filter by downloadable + CC licenses.

## UI kits

- [Kenney UI Pack](https://kenney.nl/assets/ui-pack) — CC0 UI elements with SVG sources.
- [Game UI Database](https://www.gameuidatabase.com) — reference screenshots, not assets.
- [Figma community](https://www.figma.com/community) — search "game UI".

## Audio

- [Freesound](https://freesound.org) — CC0 / CC BY sounds, check each file.
- [Kenney Audio](https://kenney.nl/assets/category:Audio) — CC0 SFX and jingles.
- [OpenGameArt audio](https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=13) — mixed licenses.

## Textures

- [Kenney Textures](https://kenney.nl/assets/category:Textures) — CC0 patterns and skyboxes.
- [Poly Haven](https://polyhaven.com) — CC0 HDRIs, textures and models.
- [ambientCG](https://ambientcg.com) — CC0 PBR materials.

## Tools

- [TexturePacker](https://www.codeandweb.com/texturepacker) — spritesheet packing.
- [Blender](https://www.blender.org) — free 3D editor, exports glTF.
- [Aseprite](https://www.aseprite.org) — pixel art editor.
